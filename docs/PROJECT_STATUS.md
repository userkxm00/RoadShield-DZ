## Current product boundary
The first validation loop is intentionally narrow:

> Detect candidate road-hazard events from smartphone motion/location signals, geolocate them, and corroborate repeated observations into a confidence-bearing road-condition event.

RoadShield is **not** currently defined as:
- a navigation application;
- an accident predictor;
- a replacement for Algeria's official road-accident systems;
- a guaranteed safety system;
- a paid AI/API-dependent product.
